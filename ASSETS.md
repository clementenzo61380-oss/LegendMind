# ASSETS.md — Graphismes et sons à trouver ou faire faire

Tout ce qui est listé ici est **remplacé pour l'instant par des formes simples** (cubes, boules, cônes).
Style commun : **anime fantasy 3D**, couleurs vives, prévu pour le cel-shading (peu de détails peints
dans les textures, aplats de couleur, pas de réalisme). Format conseillé : **glTF 2.0 (.glb)**.

Consignes techniques communes pour les modèles :
- Échelle : 1 unité = 1 mètre. Personnage humain ≈ 1,75 m. Pieds à l'origine, regard vers −Z.
- Low/mid poly (personnage ≈ 10–25 k triangles, décor ≈ 0,5–5 k).
- Textures en aplats (couleur de base), 1024 ou 2048 px, pas de « normal map » réaliste.
- Normales lissées conseillées pour le contour noir (évite les trous sur les arêtes).

Statut : ⬜ à trouver · 🟨 trouvé/en cours · ✅ intégré
